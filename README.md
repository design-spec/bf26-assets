# bf26-assets

Статичні JS/CSS для лендінгу BF26 (kid.allright.com, Webflow). Віддаються через jsDelivr:

```
https://cdn.jsdelivr.net/gh/design-spec/bf26-assets@<тег>/bf26.js
https://cdn.jsdelivr.net/gh/design-spec/bf26-assets@<тег>/bf26.css
```

Кожне оновлення — новий тег (`v1.0.1`, …), у Webflow міняється лише версія в посиланнях. Файли за тегом незмінні, кеш скидати не потрібно.

Джерело: `bf26-webflow/code` (локальний пакет).
